# نصب و استفاده — ویندوز

## ۱) نصب

1. فایل **`Farday Roshan_x64-setup.exe`** را دوبار کلیک کنید.
2. اگر ویندوز پیام «Windows protected your PC» داد: **More info → Run anyway**
   (فایل نصب امضای تجاری ندارد چون پروژه محلی است).
3. نصب برای **همین کاربر** انجام می‌شود — به دسترسی Administrator نیاز ندارد.
4. آیکن «Farday Roshan» در منوی استارت و روی دسکتاپ ظاهر می‌شود.

> نیازمندی: ویندوز ۱۰ یا ۱۱ (۶۴ بیتی).
> **نه Node لازم است، نه دیتابیس، نه انترنت — و نه دسترسی Administrator.**
>
> **WebView2**: نصب‌کننده خودِ نصب‌کنندهٔ WebView2 را همراه دارد
> (`webviewInstallMode = embedBootstrapper`). یعنی اگر روی کمپیوتری WebView2
> نبود، نصب بدون انترنت هم کامل می‌شود. (اگر ویندوز شما نسخه‌ی خیلی قدیمی
> WebView2 داشته باشد، نصب‌کننده پیام روشن می‌دهد.)

## ۲) اولین ورود

| مورد | مقدار پیش‌فرض |
|---|---|
| نام کاربری | `admin` |
| رمز | `admin123` |

بعد از ورود: **تنظیمات → تغییر رمز عبور من** → رمز را عوض کنید.

## ۳) تنظیم اولیه (۵ دقیقه)

1. **مشخصات شرکت**: نام، آدرس، سال مالی، مدیر مالی، سرپرست + ماشینری.
2. **تنظیمات → فهرست‌های کشویی**: اقلام و مواد (ماسه، ریگ، ۰۱۹، ۰۲۸…)، انواع مصرف، پرداخت‌کنندگان.
3. **کارمندان** و **مشتریان** را وارد کنید (کدها خودکار پیشنهاد می‌شوند).
4. اگر از سیستم قبلی بدهی دارید: در فورم مشتری فیلد **بدهی اولیه** را پر کنید.

## ۴) کار روزانه

| کار | مسیر |
|---|---|
| ثبت بل فروش | فروشات → ＋ بل فروش نو (شماره خودکار) |
| دریافت پول | رسیدات → ＋ رسید نو |
| ثبت مصرف | مصارف → ＋ مصرف نو |
| حضور و غیاب | حضور و غیاب → نمای ماهانه → کلیک روی خانه هر کارمند |
| معاش ماه | معاشات → ورق معاش → ذخیره |
| چاپ | در فهرست فروشات دکمه «چاپ»، در معاشات تب «سابقه اسناد» → «رسید» |

## ۵) جای معلومات

```
C:\Users\<نام کاربر>\AppData\Roaming\af.farday.roshan\
├── farday.db            ← تمام معلومات
└── backups\             ← پشتیبان‌های ساخته‌شده
```

## ۶) انتقال به کمپیوتر دیگر

1. روی کمپیوتر قدیم: **پشتیبان‌گیری → ساخت پشتیبان تازه**.
2. فایل `.db` را از مسیر بالا (پوشه `backups`) روی فلش کاپی کنید.
3. روی کمپیوتر نو: برنامه را نصب و یک بار باز کنید.
4. فایل پشتیبان را در پوشه `backups` کمپیوتر نو کاپی کنید → **پشتیبان‌گیری → بازگردانی**.
5. برنامه را ببندید و دوباره باز کنید.

> کمپیوتر نو انترنت نمی‌خواهد؛ فقط همان فایل کافی است.

## ۶٫۵) اگر روی این کمپیوتر برنامه‌ی دیگری پورت ۴۳۱۷ را گرفته باشد

خودکار حل می‌شود: برنامه ابتدا پورت ثابت ۴۳۱۷ را امتحان می‌کند و اگر آزاد
نبود، سرویس داخلی روی **هر پورت آزادی** بالا می‌آید و پنجره به همان آدرس
می‌رود (خط `FARDAY_PORT` در `api.log`). کاربر چیزی نمی‌بیند و کاری نمی‌کند.

## ۶٫۶) فراموشی رمز مدیر (بدون پشتیبانی، بدون انترنت)

سه راه — هر سه کاملاً محلی:

1. **از خود برنامه:** اگر صفحه‌ی «برنامه بالا نیامد» را دیدید، دکمه‌ی
   «بازنشانی رمز مدیر» را بزنید.
2. **از خط فرمان** (Windows → Run یا CMD):
   ```bat
   "%LOCALAPPDATA%\Programs\Farday Roshan\Farday Roshan.exe" --cli --reset-admin
   ```
   رمز کاربر `admin` به `admin123` برمی‌گردد (نقش: مدیر). اگر کاربر admin
   پاک شده باشد، دوباره ساخته می‌شود. داده‌ها دست نمی‌خورند.
3. **دیدن پشتیبان‌ها و وضعیت داده:**
   ```bat
   "%LOCALAPPDATA%\Programs\Farday Roshan\Farday Roshan.exe" --cli
   "%LOCALAPPDATA%\Programs\Farday Roshan\Farday Roshan.exe" --cli --list-backups
   ```

> همین ابزار اگر WebView2 خراب باشد هم کار می‌کند، چون پنجره‌ی گرافیکی باز نمی‌کند.

## ۷) اگر برنامه باز نشد

| نشانه | راه‌حل |
|---|---|
| پنجره سفید می‌ماند | ۱۰ ثانیه صبر کنید؛ اگر نشد برنامه را کامل ببندید و باز کنید |
| «سرویس محلی در دسترس نیست» | برنامه را ببندید، `Task Manager` را باز کنید و اگر `node.exe` مانده بود آن را ببندید، بعد برنامه را باز کنید |
| خطای ویندوز Defender | فایل نصب را از Block خارج کنید (Properties → Unblock) |

## ۸) ساخت نصب‌کننده (برای توسعه‌دهنده)

```bat
git pull
npm install
npm run desktop:build
```

اگر این کمپیوتر برای این دستور **انترنت ندارد** (نصب‌کننده باید `node.exe`
را همراه داشته باشد و آن را از nodejs.org می‌گیرد)، دو راه:

```bat
:: راه ۱ — فایل ZIP نود را یک بار از جایی با انترنت بگیرید و همان را بدهید
npm run desktop:build:offline -- "D:\node-v22.23.2-win-x64.zip"

:: راه ۲ — بدون انترنت، ولی مستقل نبودن نصب‌کننده (فقط برای تست)
node scripts/build-desktop-api.mjs --no-node
```

`npm run desktop:build` عمداً **سخت‌گیر** است و در سه حالت ساخت را متوقف
می‌کند تا هیچ‌وقت نصب‌کننده‌ای ساخته نشود که روی کمپیوتر دیگر باز نشود:

1. `node.exe` داخل بسته نباشد،
2. **باینری ویندوزی دیتابیس** (`@libsql/win32-x64-msvc`) جا افتاده باشد
   — این مهم است اگر ساخت روی لینوکس/مک انجام شود، چون npm آن بسته را
   فقط روی ویندوز نصب می‌کند؛ اسکریپت خودش آن را از npm می‌گیرد،
3. `node.exe` فایل اجرایی معتبر ویندوز ۶۴بیتی نباشد (بررسی امضای PE).

### تأیید نهایی روی کمپیوتر نصب‌شده

بعد از نصب، **تنظیمات → دیتابیس و ساختار** را باز کنید: کارت
«اجرای بدون نصب اضافی» باید نشان **آماده** داشته باشد (موتور دیتابیس،
پوشه‌ی داده قابل نوشتن، پلتفرم و حافظه). اگر قرمز بود، یعنی همین نسخه
روی این کمپیوتر مشکل دارد و باید دوباره بسته‌بندی شود.

## ۹) پشتیبان‌گیری خودکار (پیشنهادی)

`Task Scheduler` → Create Task → روزانه ساعت ۲۰:۰۰ → Action:

```
Program:   C:\Program Files\Farday Roshan\api\node.exe
Arguments: "C:\Program Files\Farday Roshan\api\cli\backup.js"
```

(مسیر نصب بسته به انتخاب شما در جریان نصب است.)
