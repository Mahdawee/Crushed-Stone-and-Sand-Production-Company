# بررسی رابط کاربری (بدون مرورگر)

سه اسکریپت، همه با `node` و بدون وابستگی سنگین:

```bash
npm run test:ui      # هر سه با هم
```

| فایل | چه چیزی را تضمین می‌کند |
|---|---|
| `layout.test.mjs` | قواعد CSS و کد کامپوننت را تطبیق می‌دهد: دکمه سه‌خط/ضربدر فقط در حالت کشو، ریل ۶۴px، پنل شناور، باز شدن تقویم با کلیک، ورود دستی، Esc… |
| `dom.test.mjs` | **DatePicker را واقعاً mount می‌کند** (jsdom + build واقعی Vite) و با کلیک/تایپ/Esc آزمایش می‌کند. |
| `sidebar.test.mjs` | **Layout را واقعاً mount می‌کند** و هر دو حالت سایدبار را می‌آزماید: لپ‌تاپ (بدون سه‌خط/ضربدر، ریل، پنل شناور، آکاردئون) و باریک (سه‌خط، بستن با ×، backdrop، Esc). |

`entry.tsx` ورودی مشترک بسته است و `vite.config.mjs` ماژول `lib/session` را با
`session-mock.tsx` عوض می‌کند تا بدون شبکه/توکن اجرا شود.

> این تست‌ها مرورگر واقعی نیستند؛ اما رفتار DOM و تطابق CSS را می‌سنجند،
> پس دیگر «کد کامپایل شد ولی دکمه کار نمی‌کرد» پنهان نمی‌ماند.
