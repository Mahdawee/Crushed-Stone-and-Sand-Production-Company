⚠ نسخه‌ی Node آماده نیست

۲) این کار چه می‌کند (و چه نمی‌کند)

⚠ برگشت‌ناپذیر است.
  • همه‌ی فروشات، رسیدات، مصارف، معاشات، حضور و غیاب، کارمندان و مشتریان پاک می‌شوند.
  • سطل بازیافت هم پاک می‌شود — «بازگرداندن» بعد از این کار ممکن نیست.
  • لاگ فعالیت، فهرست‌های سفارشی، ماشینری و مشخصات شرکت حذف می‌شوند.
  • پشتیبان‌های قبلی و لایسنس فعال هم پاک می‌شوند (تأیید مشتری قبلی نباید بماند).
  • پشتیبان خودکار از همین لحظه گرفته می‌شود و در پوشه‌ی backups می‌ماند — تنها راه برگشت.
  • بعد از صفر شدن، کاربر مدیر admin / admin123 و «مشتری گذری» دوباره ساخته می‌شوند تا سیستم قابل ورود باشد.

اگر برنامه باز است، اول آن را ببندید: دیتابیس قفل است و صفر کردن از بیرون می‌تواند داده را نیمه‌پاک بگذارد. (اگر برنامه باز باشد، ابزار از راه خودش انجام می‌دهد و می‌گوید.)

۳) تأیید صریح

صفر کردن بدون این دو، اجرا نمی‌شود
دیتابیس آماده نیست — صفر کردن انجام نمی‌شود.
هیچ داده‌ای تغییر نمی‌کند. اگر دیتابیس خراب است، از «ابزار نجات» استفاده کنید: --recovery --repair-db
برنامه باز است. صفر کردن از راه سرویس خودِ برنامه انجام می‌شود. نام کاربری و رمز مدیر را وارد کنید (پیش‌فرض admin / admin123).
کلید لازم نیست. برای صفر کردن، تیک زیر را بزنید و عبارت صفر کردن را تایپ کنید. قبل از هر تغییری یک پشتیبان خودکار گرفته می‌شود.
